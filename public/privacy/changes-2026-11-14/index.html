1. 지금 방침이 빠뜨렸거나 틀리게 적은 것

아래 9가지는 회사가 이번에 새로 시작하는 일이 아닙니다. 회사가 이미 이렇게 처리하고 있었는데, 지금 방침에 빠졌거나 틀리게 적혀 있던 것입니다. 새 방침에서 사실대로 바로잡았습니다.

#새 방침의 자리지금 방침실제(새 방침)
12-가. 폰 안에 저장하는 정보알림 시각 설정, 칵테일 결과, 닉네임을 '외부로 전송되지 않는 정보'로 적었습니다.쉐-킷할 때마다 그날 칵테일 종류, 감정 개수와 긍정 감정 비율의 구간, 라벨 수, 사진을 붙였는지, 쉐-킷한 시, 알림 시각(몇 시인지만) 같은 요약 값이 이용 통계로 Google Firebase에 갑니다. 닉네임은 지금 방침 제2항 나·다에 적힌 대로 오류 진단과 결제 확인 때 회사 서버로 갑니다.
22-나. 기기 식별자(Android)기기 식별자는 '앱을 삭제하면 소멸'한다고 적었습니다.기기 식별자는 Android 기기 고유값(ANDROID_ID)을 되돌릴 수 없게 바꾼 값입니다. 앱을 다시 설치하면 같은 값이 다시 만들어지고, 폰을 초기화하면 바뀝니다.
32-라. 이용 통계와 오류 정보이용 기록, 구독 상태, 오류 정보, 기기 모델·운영체제 버전만 적었습니다. iOS는 '오류 정보를 회사 서버로 전송하지 않는다'고만 적었습니다.접속 IP 주소로 짐작한 나라·도시, 앱 설치 식별값, iOS 앱 공급자용 기기 식별값(IDFV), 언어·시간대, 화면 이동 기록(Android), 골드·칵테일 색·가니시 같은 앱 설정 상태, 기록 알림이 울렸는지와 늦은 정도, 정확한 알람 권한과 앱 절전 상태(Android), 앱을 켤 때마다 남는 세션 기록, 원격 설정 요청(설치 ID와 그 인증 정보, 앱·기기 정보, 접속 IP 주소 등)도 갑니다. Android 앱은 기록 알림과 자동 백업의 결과(기록 알림이면 그때의 정확한 알람 권한·앱 절전 상태, 그때 생긴 오류 진단 기록 포함)를 앱을 열지 않은 때에도 보냅니다. 폰을 다시 켜거나 앱이 업데이트될 때처럼 앱이 화면 없이 켜질 때에도 앱 설정 상태를 다시 적어 보낼 수 있습니다. iOS 앱도 비정상 종료되면 오류 정보를 Google Firebase로 보냅니다.
42-사. 서버 접속 기록 · 15. 웹사이트적지 않았습니다.앱이 회사 서버와 통신하면 접속 IP 주소, 앱·기기 정보, 요청 시각, 호출한 기능이 자동으로 남습니다. 라운지를 쓰지 않는 Android 이용자도 오류 진단 기록을 보내거나 골드 결제를 확인할 때 남습니다. 웹사이트 mojitto.bar 를 열면 IP 주소 등 접속 정보가 사이트를 띄우는 GitHub Pages(GitHub)와 글꼴을 내려주는 jsDelivr 에 전달됩니다.
52-차·3. 메일 문의메일로 받은 문의·신고·요청을 적지 않았습니다.보낸 메일 주소와 메일에 적은 내용을 처리합니다. 마지막으로 메일을 주고받은 날부터 1년 보관합니다(라운지 계정 삭제 요청은 답장한 날부터 30일, 골드 결제·환불에 관한 불만·분쟁은 3년).
63. 오류 정보 보관따로 적지 않아, 통계의 '이벤트 2개월'에 묶인 것처럼 읽혔습니다.오류 수집 도구 안의 오류 정보는 수집한 날부터 90일이 지나면 지우기 시작합니다. 분석용 사본은 60일 보관합니다.
73. 설치 식별자·통계 보관적지 않았습니다.설치 식별자(Firebase 설치 ID)는 삭제를 요청할 때까지 두고, 요청한 날부터 180일 안에 지웁니다. 기간이 끝난 통계는 Google이 한 달에 한 번 지워 최대 한 달 더 남을 수 있습니다.
86. 문의 메일함 위탁적지 않았습니다.문의 메일함(Gmail)을 위탁에 넣었습니다. 지금은 개인용 계정이라 처리 위탁 약관 대신 Google의 일반 서비스 약관과 개인정보처리방침을 따릅니다.
911·15. 통계 수집 거부 방법'기기의 운영체제 설정에서 통계 수집을 제한할 수 있다'고 적었습니다.이 문장은 사실이 아니어서 지웠습니다. 앱 2.0 전의 판에는 앱 안에서 통계를 끄는 설정이 없습니다. 앱 2.0부터는 더보기 › 앱 정보 › 이용 통계·오류 정보에서 끌 수 있습니다.
